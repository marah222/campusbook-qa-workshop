# One-day QA Workshop — 100-point assessment

| Category | Points |
|---|---:|
| User story and acceptance criteria | 15 |
| Test design and risk analysis | 20 |
| Manual / exploratory test evidence | 10 |
| Individual unit, API and UI contributions | 20 |
| Team automation integration | 10 |
| Maintainability (6) and performance interpretation (4) | 10 |
| CI evidence and release decision | 10 |
| Collaboration and human peer review | 5 |
| **Total** | **100** |

Evaluate individual reasoning and execution evidence rather than raw number of passing tests. A valid failing test identifying a real defect can earn full marks. Shared deliverables should not obscure individual work.
